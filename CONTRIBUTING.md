# Вклад в репозиторий

Перед добавлением исполняемого кода:
- указывайте версию .NET и `System.Data.SQLite`;
- сохраняйте исходные UUID Oracle-модели;
- различайте факты XML, выводы анализа и предположения;
- не добавляйте сгенерированный DDL как исполняемый, пока типы/ключи не проверены;
- добавляйте тесты для маппинга NULL, GUID, дат и параметров SQLite.

Не загружайте реальные базы с персональными/конфиденциальными данными в публичный репозиторий.
