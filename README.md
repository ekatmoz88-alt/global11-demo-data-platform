# global11-demo-data-platform

Технический репозиторий для исследования модели Oracle Data Modeler `global11_demo` и C#-слоя доступа к SQLite `DbStationary.Data`.

> **Статус:** восстановленная документация и инвентаризация исходных материалов. Это не готовое приложение и не миграционный пакет. Связь между Oracle OLAP-моделью и SQLite `MainDB.db3` пока не подтверждена.

## Состав

- `sources/oracle/global11_demo.zip` — исходный архив Oracle Data Modeler.
- `src/DbStationary.Data/` — предоставленные C#-файлы доступа к SQLite.
- `docs/model/` — OLAP- и ER-диаграммы Mermaid и заметки по восстановлению модели.
- `docs/sql/` — SQL-каркас для ревью; намеренно не исполняемый DDL.
- `data-dictionary/` — Excel-словарь данных, извлечённый из XML.
- `docs/architecture/` — архитектурные заметки и границы достоверности.

## Важные ограничения

1. В исходном архиве используются логические коды типов `LOGDTxxx`; их отображение на типы конкретной версии Oracle не было достоверно восстановлено. Поэтому SQL-файл — спецификация для ревью, не скрипт для запуска.
2. Наличие `MainDB.db3` следует из строки подключения в `ConnectionFactory.cs`; сам файл базы данных не предоставлен.
3. `SQLiteMaps.cs` описывает отображение отдельных запросов в модели приложения, но SQL-запросы, модели `Common.Data.Models` и схема SQLite не предоставлены.
4. Совпадение имён/полей между Oracle-моделью и SQLite не считается доказательством связи между системами.
5. В исходном коде есть вопросы управления временем жизни соединения и команд; см. архитектурный обзор.

## Сборка

Проект `.csproj` не добавлен намеренно: неизвестны целевая версия .NET, версия `System.Data.SQLite`, а также исходные сборки `Common.Data.Models` и `DbStationary.Models`. Добавление произвольных версий сделало бы проект недостоверным.

## Предлагаемый следующий этап

1. Получить `MainDB.db3` или SQL-дамп схемы SQLite.
2. Получить модели `UserModel`, `CaseModel`, `DossierModel`, `UmmsPersonModel`, `UmmsDocumentModel` и SQL-запросы, вызывающие `SQLiteMaps`.
3. Установить соответствия между SQLite, C#-моделями и сущностями Oracle только по ключам и запросам.
4. После подтверждения типов и ключей сформировать исполняемый Oracle/SQLite DDL и тесты.
