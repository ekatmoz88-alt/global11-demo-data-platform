03 · Version and implementation constraints

  • Oracle 11g does not support identity columns; key generation must use a version-compatible approach such as sequences and triggers or application-side generation.
  • Bitmap indexes should not be prescribed automatically for frequently updated OLTP tables.
  • Interval partitioning does not itself archive or automatically remove old data.
  • REFRESH FAST ON COMMIT is not confirmed; eligibility must be checked against the actual materialized-view definition, for example with DBMS_MVIEW.EXPLAIN_MVIEW.
  • Reports must distinguish claim-level grain from claim-detail grain when a claim can contain multiple loss details.
